## ЗАДАЧА 2 — stateful-пагинация (Load More)

- `POST /api/search` принимает `page: {marketplace: N}` и `cursor: {marketplace: token}`.
- Ответ возвращает `next_page` и `next_cursor` для каждого маркетплейса (если `truncated`).
  Kufar отдаёт cursor-токен (base64 `{"t":"abs","p":N,"pit":...}`), Onliner/21vek — номер страницы.
- «Загрузить ещё» отправляет полученные page/cursor и **докидывает** товары в Zustand-стор
  (дедуп по url); парсеры останавливаются при пустом ответе.
- Проверено живьём: 1-й запрос kufar 93 / onliner 200 / 21vek 60; 2-й запрос по
  page/cursor → kufar +100, onliner +200 (все новые страницы), 21vek — 0 (страницы повторяются,
  дедуп). Суммарно kufar до ~500, onliner до 1000.
